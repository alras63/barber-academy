# MensCut Academy

Сайт академии мужских стрижек. Вся визуальная концепция построена вокруг
**фирменной стены** с логотипом и живой листвой: сайт — продолжение стены,
а первый экран — не лендинг, а вход в академию.

Основной продукт — **курс с нуля до профессионала**. Прийти можно без опыта.

## Концепция: стена как портал

Референс по атмосфере — Menspire (menspire.com): спокойная печатная
подача вместо рекламного лендинга.

**Движения на сайте нет.** Ни анимаций, ни переходов, ни эффектов на
прокрутке — по решению заказчика после тестов на телефоне. Всё содержимое
показывается сразу. Слушателей прокрутки на странице ноль, чтений
геометрии во время прокрутки ноль: браузеру нечего пересчитывать, поэтому
и рывкам взяться неоткуда. Атмосферу держат кадры и типографика.

Маршрут по академии:

```
Титул (белый лист, полоса стены понизу)  →  Стена (кадр + реплика)
→ Перезагрузка → Курс с нуля (+ вопросы) → Программа
→ Академия и прогноз → Преподаватели → Ученики (+ видео-истории)
→ После выпуска → Запись
```

Между главами идут **развороты во всю ширину** — кадр и ни одного слова.
Это и есть «открытая книга»: развернул — слева мысль, справа картинка.
Слов на кадрах нет намеренно: чтобы белый текст читался поверх светлого
бетона, нужна шторка, а она затемняет фотографию почти до чёрного. Текст
живёт на белом, кадры — сами по себе.

Тёмное на сайте появляется ровно дважды: на входе (титул и портал) и на
выходе (запись и подвал). Всё между ними — один белый разворот на единой
сетке: метка секции слева, заголовок и текст с одной вертикали справа.

Приёмы, которые держат ощущение одного пространства:

- **Приоткрытая дверь.** Титул — белый лист; стена лежит полосой у нижнего
  края и обесцвечена (`main-bw-*.webp`, готовится при сборке). Цвет
  включается на следующем экране, на самой стене.
- **Стена.** Кадр полосой во всю ширину и реплика под ним, на белом.
  Слова специально не лежат на фотографии: фактура листвы спорит с
  текстом, и глазу не за что зацепиться. На белом реплика стоит на той же
  вертикали, что и все заголовки сайта, и читается первой.
- **Программа.** Шесть шагов обычным списком. Раньше шаги сменяли друг
  друга в закреплённом кадре.
- **Белое полотно и тёмные акценты** — свет ведёт по странице.

## Цвет и типографика

**Основа — белый.** Палитра намеренно короткая: четыре значения вместо
россыпи оттенков серого.

```
--paper      #ffffff   основа
--ink        #0a0a0a   текст и тёмные полотна
--ink-muted  #6b6b6b   второстепенный текст (5.2:1 на белом)
--line       #e6e6e6   волосяные линейки
```

**Тёмный фон — акцент, а не фон по умолчанию.** Он остаётся ровно в двух
местах: вход (полоса стены на титуле и портал) и выход (запись и подвал).
Всё между ними — один белый разворот. Единственный цвет на сайте даёт сама
стена, и включается он только в портале — ей не с чем конкурировать.

Карточки учеников и преподавателей набраны как печатный разворот: кадр
отдельно, подпись под ним чёрным по белому. Ни затемняющей шторки, ни
второй палитры «по тёмному» — приём взят из референса (menspire.com).

**Отступы.** Поля секций меряются шириной окна, а не высотой: на телефоне
26vh давали по четверти экрана пустоты сверху и снизу у каждой из десяти
секций. Сейчас 84 px на телефоне и 216 px на мониторе, боковые поля —
24 и 86 px. Полосы-развороты идут во всю ширину без полей.

**Одна сетка.** Метка секции — в узкой левой колонке, заголовок, лид и
текст — в широкой правой. Эта вертикаль повторяется в каждой секции,
включая титул и программу; сетки с фотографиями намеренно идут во всю
полосу — контраст отступа и полного разворота и держит ритм.

Плёночное зерно, виньетка, рельса глав и полоса прогресса убраны —
это был визуальный шум, который съедал воздух. Осталась только шапка.

**Шрифты** (локальные, вариативные, с кириллицей):

- **Jost** — геометрический гротеск. Заголовки набраны светлым начертанием
  в верхнем регистре с широкой разрядкой: так держится архитектурная
  сдержанность референса.
- **Golos Text** — гротеск Paratype: основной текст и подписи.


## Тексты

Копирайтинг и список фактов, которые нужно подтвердить (срок обучения,
стоимость, формат, контакты), — в отдельном файле **`КОНТЕНТ.md`**.
Там же — формула, по которой пишутся истории учеников, и вопросы для сбора
отзывов и видео.

## Структура

```
index.html        — разметка и контент разделов
css/fonts.css     — локальные шрифты (Jost, Golos Text)
css/styles.css    — дизайн-система (токены, типографика, секции, адаптив)
js/data.js        — БАЗА ДАННЫХ: ученики, преподаватели, видео-истории
js/main.js        — рендер карточек, лента учеников, видео-истории, форма
assets/fonts/     — локальные веб-шрифты
assets/img/bg/    — фирменные фоны в трёх ширинах (scripts/build-assets.py)
assets/img/icons.svg — спрайт фирменных иконок (scripts/build-icons.py)
```

Зависимостей и сборки нет — статический сайт. Открывается напрямую или
отдаётся любым статик-хостингом (GitHub Pages, Netlify, Vercel).

## Видео

Фоновых ambient-роликов на сайте нет и не планируется: движение снято
полностью, а зацикленное видео — это движение по определению. Слоты
`heroLoop`, `portalScrub` и `ambient-*` удалены вместе с ним.

Осталось одно место, где видео уместно, — **истории выпускников**: там
ролик запускает сам человек кнопкой. Путь к файлу задаётся в поле `url`
массива `VIDEOS` в `js/data.js`; пока оно пустое, карточка остаётся
неподвижной обложкой 16:9.

## База учеников (как пополнять)

Все данные — в `js/data.js`. Это основа будущей базы: структура плоская и
предсказуемая, её легко перенести в CMS/БД без переписывания интерфейса.

**Добавить ученика** — допишите объект в массив `STUDENTS`:

```js
{
  id: "st-2025-009",              // уникальный идентификатор
  name: "Имя Фамилия",
  year: "2025",                   // год выпуска (бейдж на карточке)
  from: "Кем был до академии",    // точка старта (для будущей аналитики)
  now: "Кто сейчас",              // результат/должность
  story: "Короткая история пути",
  result: "Ключевой результат",
  photo: "assets/img/students/имя.jpg", // фото; null → монограмма
  tags: ["с нуля", "трудоустроен"]
}
```

Фото кладите в `assets/img/students/`, пропорции 5:7 (600×840). Подпись
стоит под кадром, поэтому снимок ничем не перекрывается — кадрируйте
свободно. Если `photo: null` — карточка показывает монограмму (инициалы)
и остаётся аккуратной.

Сейчас в карточках стоят **временные демо-портреты** (StockSnap, CC0) —
список и условия замены в `assets/img/ИСТОЧНИКИ.md`.

**Преподаватели** — массив `TEACHERS` (только профессиональная информация:
роль, специализация, навыки; без личного).

**Видео-истории** — массив `VIDEOS`: `poster` (обложка 16:9) и `url` (файл
видео). Живут подразделом внутри блока учеников. Когда указан `url`,
кнопка Play проигрывает историю прямо в карточке.

## Форма записи

Форма «Записаться» обрабатывается на стороне браузера (демо-подтверждение).
Для продакшена подключите отправку на бэкенд/CRM в обработчике `#enrollForm`
в `js/main.js`.
