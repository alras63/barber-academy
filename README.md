# Manspire Academy

Сайт академии мужских стрижек. Концепция построена вокруг **фирменной стены**
с логотипом и живой листвой: сайт — это продолжение стены, а первый экран —
не лендинг, а вход в академию.

Основной продукт — **курс с нуля до профессионала**. Прийти можно без опыта.

## Идея дизайна

- **Стена как интерфейс.** Стена встречает на первом экране (портал) и
  возвращается в финале (вход в академию) — маршрут замыкается в кольцо.
- **Листва прорастает по сайту.** Силуэты монстеры и папоротника (SVG)
  аккуратно появляются на стыках блоков и «прорастают» при прокрутке —
  дозированно, не в каждом блоке.
- **Маршрут, а не набор блоков.** Философия → курс с нуля → об академии и
  прогноз развития → перезагрузка → преподаватели → ученики → видео-истории →
  трудоустройство → вход. Сверху — тонкий индикатор пути.
- **Премиальный минимализм** в духе Manspire, но с собственной айдентикой:
  тёмная атмосфера стены + светлые полотна, неоновое свечение логотипа как
  акцент, серифный дисплейный шрифт (Cormorant) + чистый Manrope.

## Структура

```
index.html        — разметка и весь контент разделов
css/styles.css    — дизайн-система (токены, секции, адаптив)
js/data.js        — БАЗА ДАННЫХ: ученики, преподаватели, видео-истории
js/main.js        — рендер карточек, reveal-анимации, прорастание листвы, форма
assets/img/       — изображения (wall.jpeg — фирменная стена)
```

Зависимостей и сборки нет — статический сайт. Можно открыть `index.html`
напрямую или отдать любым статик-хостингом (GitHub Pages, Netlify, Vercel).

## База учеников (как пополнять)

Все данные — в `js/data.js`. Это основа будущей базы: структура плоская и
предсказуемая, её легко перенести в CMS/БД без переписывания интерфейса.

**Добавить ученика** — допишите объект в массив `STUDENTS`:

```js
{
  id: "st-2025-009",              // уникальный идентификатор
  name: "Имя Фамилия",
  year: "2025",                   // год выпуска (бейдж на карточке)
  from: "Кем был до академии",    // точка старта (для будущей аналитики)
  now: "Кто сейчас",              // результат/должность
  story: "Короткая история пути",
  result: "Ключевой результат",
  photo: "assets/img/students/имя.jpg", // фото; null → красивая монограмма
  tags: ["с нуля", "трудоустроен"]
}
```

Фото кладите в `assets/img/students/` и указывайте путь в `photo`.
Пока фото нет — карточка автоматически показывает монограмму (инициалы).

**Преподаватели** — массив `TEACHERS` (только профессиональная информация:
роль, специализация, навыки; без личного).

**Видео-истории** — массив `VIDEOS`. Поля `poster` (обложка) и `url` (файл
видео). Когда указан `url`, кнопка Play проигрывает видео прямо в карточке.

## Форма записи

Форма на первом экране «Записаться» сейчас обрабатывается на стороне браузера
(демо-подтверждение). Для продакшена подключите отправку на бэкенд/CRM в
обработчике `#enrollForm` в `js/main.js`.

## Доступность и производительность

- Уважает `prefers-reduced-motion` (отключает параллакс и анимации).
- Семантическая разметка, alt-тексты, aria-подписи, клавиатурная навигация.
- Без внешних JS-библиотек; шрифты — Google Fonts с системными фолбэками.
